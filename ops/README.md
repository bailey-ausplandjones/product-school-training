# ops/ — recurring weekly outputs

The numbered folders (`01-orient/` … `08-stakeholders/`) hold **one-time project
artifacts** — the capstone narrative, one artifact per module. This folder holds
**recurring outputs** that would otherwise flood them and break that narrative.

| Path | What lands here | Produced by |
|---|---|---|
| `ops/status/` | `YYYY-MM-DD-status.md` — Friday status updates | [skills/friday-status.md](../skills/friday-status.md) |
| `ops/research/inbox/` | **You drop raw feedback here.** Tickets, NPS exports, survey text, interview notes — any format | — |
| `ops/research/` | `YYYY-Www-research.md` — weekly synthesis of the inbox | [skills/weekly-research-synthesis.md](../skills/weekly-research-synthesis.md) |
| `ops/competitive/` | `YYYY-MM-DD-pulse.md` — weekly competitor pulse | [skills/competitive-pulse.md](../skills/competitive-pulse.md) |

Each workflow writes a new dated file. None of them overwrite an existing file,
and none edit a project artifact without asking first — see the "Boundaries"
section in each skill.
